# Лабораторная работа № 3. Виртуальная память

Репозиторий содержит программы на C# (.NET 10) для изучения механизмов выделения виртуальной и физической памяти в Linux, а также влияния кэша процессора и TLB на скорость работы с памятью.

## Структура проекта

* **`Exp1/`** — **Опыт 1 («Выделить — не значит получить»)**: выделение 256 МиБ через системный вызов Linux `mmap` (`MAP_PRIVATE | MAP_ANONYMOUS`) и мониторинг `VmSize`, `VmRSS` и `minor page faults` (через `/proc/self/status` и `/proc/self/stat`) на этапах выделения, первого чтения, первой и повторной записи, а также освобождения (`munmap`).
* **`Exp2/`** — **Опыт 2 («Матрица по строкам и по столбцам»)**: сравнение времени суммирования элементов одномерного массива `8192 × 8192` (`int[]`, 256 МиБ) при последовательном обходе по строкам и по столбцам (усреднение по 3 запускам).

## Требования и запуск

* **ОС:** Linux (проверено на Debian 13, ядро `6.12.57+deb13-amd64`)
* **Среда:** .NET SDK `10.0` (`net10.0`)
